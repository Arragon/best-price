# Category research

1. Record target versus hard budget, use case, must-haves, preferences, and allowed alternatives.
2. Form an open initial model pool from concise product research; do not exclude older flagships
   merely because their original new price exceeded today's used budget.
3. Run a bounded broad marketplace discovery search. Extract named models and uncertainty; do
   not calculate one price distribution across the mixed category.
4. Verify promising and unexpected models, then run focused model/bundle searches.
5. Revisit discovery only when another query has plausible information gain.

Track where each constraint came from: `user_explicit`, `user_inferred_needs_confirmation`, or
`agent_proposed`. A user-stated hard ceiling cannot be softened silently; over-budget candidates
belong in Extra with the exact overshoot.
