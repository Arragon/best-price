# New price comparison

Accept a retail quote only when it has source platform, URL, capture time, currency, exact SKU or
explicit equivalence, bundle, condition, price, and offer requirements. Keep ordinary, conditional,
and unverified prices distinct. Mock/Dry-run output is never a live quote.

Compare used and new only after checking model, capacity/color when price-relevant, included
accessories, warranty, shipping, membership, coupon, subsidy, and group-buy conditions. If they are
not equivalent, describe the difference instead of calculating a definitive saving ratio.

When equivalent: `saving_fen = new_fen - used_fen` and `saving_ratio = saving_fen / new_fen`.
Show the user's preference threshold as their policy, not a universal rule.
